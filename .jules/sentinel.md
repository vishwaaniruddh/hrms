## 2024-05-24 - [Local Storage Used for Session State]
**Vulnerability:** The application was storing sensitive authentication tokens, user IDs, and role information persistently across browser sessions using `localStorage`. Additionally, the logout function failed to explicitly remove all role-related keys.
**Learning:** This implementation persisted sensitive session data unnecessarily long, increasing the attack surface on shared devices or in scenarios where a user closes the browser without explicitly logging out. The incomplete removal of role properties during logout created a potential authorization leak where subsequent sessions on the same browser could inherit permissions.
**Prevention:** Always use `sessionStorage` for sensitive, session-bound data like authentication tokens so that they are automatically cleared when the browser window/tab is closed. Ensure that the logout/session destruction function comprehensively resets all associated state variables.
