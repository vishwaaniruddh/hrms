## 2024-05-15 - Security Learning\n**Vulnerability:** Use of localStorage for authentication token and session management.\n**Learning:** The application uses `localStorage` to store authentication tokens and sensitive user information (like id, username, roles, and permissions) in `src/utils/Common.jsx`. Using `localStorage` is insecure because it exposes the sensitive data to XSS attacks and persists even after the browser is closed.\n**Prevention:** Switch to using `sessionStorage` which is cleared when the page session ends, or better yet, `HttpOnly` cookies. Since this is a frontend change, I will update `Common.jsx` to use `sessionStorage`.
