## 2024-05-18 - Header Navigation Accessibility
**Learning:** Icon-only navigation links (frequently using classes like `nk-nav-toggle`, `nk-quick-nav-icon`, and `dropdown-toggle`) in the header lacked context for screen readers.
**Action:** Always verify that icon-only interactive elements contain a descriptive `aria-label` attribute indicating their specific purpose (e.g., "Toggle navigation", "Notifications") to improve accessibility.
