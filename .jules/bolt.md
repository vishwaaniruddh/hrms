## 2024-06-13 - [Route Code Splitting]
**Learning:** The application's `src/App.jsx` contained static imports for all its main routing components (`Member`, `MemberProfile`, `Attendence`, `Salary`), increasing the initial bundle size and potentially degrading load times. Since React 18 and Vite are used, standard `React.lazy()` with `Suspense` effectively addresses this. The codebase correctly uses `<MainLayout />` as a self-closing sibling component to the routes, not wrapping them, meaning the Suspense boundary should strictly wrap the `<Routes>` only to preserve layout structure. In this environment lacking `node_modules`, `pnpm dlx esbuild <filepath> --log-level=error` is the most reliable way to perform structural syntax checks.
**Action:** When adding new top-level application routes in the future, automatically employ `React.lazy()` and `Suspense` rather than relying on synchronous static imports to maintain frontend initial load performance.
