## 2024-05-24 - Dynamic ESLint execution without modifying package.json\n**Learning:** The project uses an older version of ESLint via a `.eslintrc.cjs` config, but running `pnpm lint` broadly or updating `package.json` dependencies introduces unnecessary file changes (such as generating `pnpm-lock.yaml`) which violates strict constraints.\n**Action:** Use `pnpm dlx eslint@8 <filepath>` to verify specific files when checking code changes locally without permanently altering the project dependencies.
