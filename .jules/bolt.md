## 2024-05-24 - Do not implicitly upgrade React dependencies
**Learning:** `pnpm build` will fail with `Rollup failed to resolve import "react-dom/client"` if the versions of `react` and `react-dom` get out of sync. This can happen easily if you run `pnpm install` without a lockfile or add a new dependency, as it might resolve one of them to v19 while the other remains at v18.
**Action:** Be extremely cautious when modifying dependencies in this project. Avoid running `pnpm install` or adding new packages unless explicitly requested by the user. If you must run a build step to verify something, ensure the versions of `react` and `react-dom` match exactly (e.g., manually installing `react-dom@^18.2.0` to match `react@^18.2.0`). And remember to clean up `package.json` afterwards if you are under a "Do not modify package.json" constraint.
