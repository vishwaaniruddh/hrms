## 2024-08-12 - Adding ARIA labels to Icon-only Navigation
**Learning:** This app heavily relies on icon-only navigation buttons (e.g. `ni-menu`, `ni-globe`, `ni-comments`, `ni-bell`) that do not provide clear context to screen readers. Adding `aria-label`s to these anchor tags makes navigation significantly more accessible. Also, adding inline JSX comments inside a React tag (e.g. `<a {...} {/* comment */}>`) breaks the syntax and causes build/render crashes. Comments must be placed between JSX tags, not inside their opening definitions.
**Action:** Always ensure icon-only buttons include descriptive `aria-label` attributes for screen readers. When adding required documentation comments, place them on separate lines between structural JSX tags to prevent fatal syntax errors.
