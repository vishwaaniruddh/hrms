## 2026-06-30 - Missing ARIA Labels on Custom UI Icon Buttons
**Learning:** The application's custom UI patterns frequently use icon-only buttons leveraging classes like .btn-icon, .nk-quick-nav-icon, .nk-nav-toggle, and .dropdown-toggle that natively lack accessibility context.
**Action:** Regularly scan for these specific classes and add aria-label attributes to these elements to ensure they are screen-reader friendly and accessible.
